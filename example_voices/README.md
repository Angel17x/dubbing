# Voces de ejemplo

Esta carpeta contiene cuatro muestras MP3 que pueden utilizarse como referencia
de clonación con XTTS:

- Roger — relajada, casual y resonante (predeterminada).
- Daniel — locutor estable.
- Eric — suave y confiable.
- Joseph Corona — clara y profesional.

Deja vacío **Audio de referencia** en el popup para utilizar Roger. Para elegir
otra voz, introduce la ruta absoluta de su MP3.

Estas muestras solo deben distribuirse y utilizarse cuando sus licencias y los
derechos de sus voces permitan clonación, redistribución y uso público. Quien
publique o utilice este repositorio es responsable de verificar esos permisos.
